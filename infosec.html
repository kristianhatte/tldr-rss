PHP2Shell — Deep Dive (45 minute read)

2026-11-10T00:00:00.000Z

PHP2Shell is a use-after-free chain that can lead to remote code execution. A crafted multipart request triggers an out-of-memory condition during session.upload_progress processing. PHP's bailout path skips cleanup, leaving stale global pointers in a long-lived worker process. A later request reclaims the freed memory and forges a zend_string length field, causing PHP to return 256 bytes of nearby heap data in a Set-Cookie header. The article demonstrates an exploit that targets PHP 8.4.26 Alpine CLI and depends on precise heap grooming.

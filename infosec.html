vLLM triples MiniMax M3 inference throughput on AMD's MI355X through systematic bottleneck chasing (6 minute read)

2026-09-11T00:00:00.000Z

AMD and Embedded LLM teams took MiniMax M3's day-0 vLLM implementation from 109.1 to 342.4 output tokens/s/GPU on AMD's Instinct MI355X, a 3.14x gain, by repeatedly asking five questions as the bottleneck kept shifting: what local shape reached each rank after tensor-parallel sharding, what work repeats every layer, which bytes actually move, whether a claimed fast path actually executed, and which queue grows once kernels stop being the limiter. RFD 301: Has anybody seen my keys?: A key-hierarchy strategy for rack-level security (12 minute read)

2026-09-09T00:00:00.000Z

Oxide published its internal design for protecting rack data at rest, rooting everything in a Shamir-shared rack secret that no attacker can recover without stealing at least K sleds or M.2 drives. Per-drive ZFS wrapper keys are derived with HKDF using SHA3-256 and an info string built from the PCI vendor ID, drive model, and serial number, so compromising one disk key leaves the others intact. The harder problem is rotation across a distributed two-phase commit: the dealer encrypts the epoch N-1 rack secret under a key derived from the epoch N secret using chacha20poly1305, keeping the old secret unrecoverable until the new configuration commits.
